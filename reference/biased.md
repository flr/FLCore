# Apply a systematic bias trend to an abundance index

Multiplies an `FLQuant` by a cumulative bias trend generated by
[bias](bias.md), so that values drift away from truth over time.

## Usage

``` r
biased(object, bias = 0.02)
```

## Arguments

- object:

  An `FLQuant` to be biased.

- bias:

  Numeric; per-year fractional bias passed to [bias](bias.md); defaults
  to 0.02.

## Value

An `FLQuant` of the same dimensions as `object` with the cumulative bias
applied.
